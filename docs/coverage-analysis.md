## 網羅率向上のボトルネック

### 1. ピアノ（24〜38%）
- 大津市内の個人ピアノ教室は50〜80件と推定されるが、大半がSEO弱く公式サイト未整備
- 補完手段: 地域情報サイト（エキテン・ジモティー）、Google Maps検索

### 2. 学習塾（50〜62%）
- 公文式は17教室を収録済みだが、大津市内には20件超と推定
- フランチャイズ系（明光義塾・スタンダード等）の全支店は未収録
- 補完手段: 各チェーン公式サイトの「校舎一覧」ページ

### 3. 英会話（50〜62%）
- ECCジュニアは大津市内30+教室が存在するが代表的なもののみ収録
- NOVA・ベルリッツ等の個人向けスクール（子ども向けコースあり）が未収録
- 補完手段: ECCジュニア公式サイトの教室検索

### 4. 武道・習字（個人道場・個人教室）
- 地域の道場・個人教室は公式情報が乏しい
- 補完手段: 大津市体育協会・大津市文化協会の加盟団体リスト
