## 補完ソース別 効果検証

### Google Maps による補完

- **有効な情報**: 営業時間（= レッスン時間帯の参考）、教室の存在確認、口コミでの「月謝目安」「曜日」の言及
- **補完効果**: 曜日・時間 **+5〜10%**、月謝 **+5%**（口コミ内に記述がある場合のみ）
- **限界**: 個人教室は Google ビジネスプロフィール未登録が多い

### ポータルサイトによる補完

**コドモブースター**（掲載18.7万件）:
- 大津市スイミング・英会話で掲載あり。大手チェーンの情報はコドモブースター側が独自に整備
- 補完効果：月謝 **+15〜20%**、対象年齢 **+10〜15%**
- 弱点：月謝が古い・概算にとどまることがある

**スクルー**:
- 大津京駅周辺のスイミング・スポーツ教室が掲載確認済み
- 補完効果：曜日・時間 **+10%**、月謝 **+5〜10%**（掲載が少ない地域では限定的）

**スイミング情報ネット**（swimming-info.net/articles/49）:
- 大津市スイミング5校の特徴記事あり。料金・コース概要が比較的充実
- 補完効果：スイミング特化で曜日 **+10%**、月謝 **+15%**

### SNSによる補完

**Instagram**:
- 髙橋バレエスタジオ・Ballet Studio L'ecrin・宮下バレエ団等のアカウント確認
- スケジュール投稿・体験募集投稿に「毎週○曜日○時〜」「月謝○円」が記載されることがある
- 補完効果：バレエ等の個人教室で曜日 **+10〜15%**、月謝 **+5〜10%**（投稿内容次第）
- ただし公式 API での自動収集は不可（手動確認のみ現実的）

**Facebook / X**: 効果は Instagram より低め。補完効果は限定的。

## 取得率改善試算

| 項目 | 現状（公式サイトのみ） | 補完後（推定） | 主要補完ソース |
|---|---|---|---|
| **曜日** | 約50〜60% | 約70〜80% | コドモブースター、スイミング情報ネット、Instagram |
| **時間** | 約45〜55% | 約65〜75% | コドモブースター、スクルー |
| **対象年齢** | 約70〜80% | 約85〜90% | コドモブースター（最も充実）、Google 検索スニペット |
| **月謝** | 約40〜55% | 約65〜75% | コドモブースター、スイミング情報ネット、口コミ |

**カテゴリ別取得率の差異**:
- **スイミング**: 最高（公式サイト単体でも曜日65%・月謝70%程度）
- **英会話**: 大手チェーンは高いが個人・小規模教室で低下（平均50〜60%）
- **ダンス（バレエ）**: 最低（月謝・曜日の非公開が多い。公式サイト単体では30〜40%程度）

## LessonMapへのインパクト

1. **スイミングは即戦力データソースとして高品質**: 大津イトマン・ニスポ・コジャック等は曜日・時間・月謝が公式サイトや口コミサイトで揃っており、スクレイピング優先度が高い
2. **英会話チェーンはコドモブースター併用で大幅補完可能**: セイハ・NOVA・ECC 等の大手は公式 + コドモブースターで対象年齢・月謝の取得率が85%超に到達見込み
3. **バレエ・個人ダンス教室が最大の課題**: 月謝非公開・要問合せの割合が高く、Instagram のスケジュール投稿からの補完が現実的な唯一手段。ただし自動化は困難
4. **「対象年齢」は比較的取得しやすく「月謝」が最も困難**: 特に個人教室・バレエ教室では月謝を公開しないビジネス慣行が根強い

| 優先度 | アクション | 期待効果 |

| **★★★ 最優先** | コドモブースター API または連携によるデータ統合 | 月謝・対象年齢の取得率を一括 +15〜20% |
| **★★★ 最優先** | スイミング情報ネット（swimming-info.net）からの大津市5校データ取得 | スイミングカテゴリの月謝・曜日を高精度補完 |
| **★★ 高優先** | Instagram 投稿の定期確認（バレエ・ダンス個人教室対象） | バレエ教室の曜日・月謝を +10〜15% 改善 |

| **★ 中優先** | Google Maps 口コミ本文の NLP 解析（月謝・曜日キーワード抽出） | 全カテゴリで月謝 +5%、曜日 +5〜8% |
| **★ 低優先** | Facebook / X からの補完 | 効果小、コスト高 |
