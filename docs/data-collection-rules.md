# データ収集ルール

LessonMapの習い事データを収集・更新する際に必ず従うルール。

---

## 基本原則

### 1. 推測禁止

確認できない情報は登録しない。ソースが確認できる情報のみ保存する。

- **NG**: 「このエリアなら月謝は約5,000円だろう」
- **NG**: 「公式サイトに書いてなかったが、他の教室と同じはず」
- **OK**: 「公式サイトの料金ページに『月謝5,500円』と明記されている」

### 2. 既存値を上書きしない

すでに登録済みのフィールドに値がある場合、新しい収集で上書きしない。  
上書きが必要な場合は手動で確認・更新する。

### 3. 取得元を記録する

`data_sources` フィールドに情報の出典を必ず記録する。

```json
"data_sources": ["official_site", "google_places"]
```

| 値 | 意味 |
|---|---|
| `official_site` | 教室の公式Webサイト |
| `google_places` | Google Places API |
| `web_search` | ウェブ検索スニペット |
| `portal_site` | コドモブースター・スクルー等のポータルサイト |
| `manual` | 手動入力・直接確認 |

## 住所ルール

### 番地レベルの住所のみ座標を付与する

数字（番地・号・丁目番号）を含まない住所は「曖昧な住所」として扱い、  
`lat` / `lng` / `geocode_accuracy` は `null` のままにする。

**曖昧な住所の例（座標null）:**
```
滋賀県大津市逢坂
滋賀県大津市坂本
滋賀県大津市（膳所駅近く）
```

**有効な住所の例（座標付与OK）:**
```
滋賀県大津市島の関１−６０
滋賀県大津市におの浜４丁目２−１２
滋賀県大津市上田上中野町779
```

### 施設名から住所を引く場合はGoogle Places APIで検索する

「○○小学校グラウンド」「○○体育館」など施設名が活動場所として記載されている場合、  
その施設の住所を Google Places API / Geocoding API で検索して取得する。  
ウェブ検索スニペットの住所をそのまま使わない。

**理由**: スニペットには誤った住所が混入することがある（打出FC事例: 打出浜15-1 → 実際は島の関1-60）

### 「活動場所の住所」と「団体の登録住所」どちらを使うか

活動場所（グラウンド・体育館・スタジオ）の住所を優先する。  
ユーザーが実際に向かう場所を示すことがLessonMapの目的のため。

## 信頼度（confidence）定義

各フィールドには対応する `_confidence` フィールドを付与できる。

| 値 | 定義 |
|---|---|
| `"high"` | 公式サイト・公式資料に明確に記載されている |
| `"medium"` | ポータルサイト・ウェブ検索スニペットから取得。正確さは高いが一次情報ではない |
| `"low"` | SNS投稿・口コミ等から取得。変更されている可能性がある |

対象フィールド: `lesson_days_confidence`, `lesson_times_confidence`, `monthly_fee_confidence`, `target_age_confidence`

---

## データ品質（data_quality）定義

`data_quality` フィールドは以下の基準で自動算出する。

| 値 | 条件 |
|---|---|
| `"high"` | 住所（番地あり）＋ 曜日・時間・対象年齢・月謝のうち2項目以上が確認済み |
| `"medium"` | 住所（番地あり）＋ 上記のうち1項目が確認済み |
| `"low"` | 住所のみ、または住所が曖昧（番地なし） |

---

## フィールド定義

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `name` | string | ✓ | 教室名 |
| `category` | string | ✓ | カテゴリ（下記参照） |
| `address` | string | ✓ | 住所（番地レベル推奨） |
| `lat` | number\|null | — | 緯度（番地なし住所はnull） |
| `lng` | number\|null | — | 経度（番地なし住所はnull） |
| `geocode_accuracy` | string\|null | — | `ROOFTOP` / `RANGE_INTERPOLATED` / `GEOMETRIC_CENTER` / `APPROXIMATE` |
| `website` | string\|null | — | 公式サイトURL |
| `phone` | string\|null | — | 電話番号 |
| `target_age` | string\|null | — | 対象年齢（例: `"3歳〜小学6年生"`） |
| `schedules` | array\|null | — | スケジュール配列（weekday / start_time / end_time） |
| `lesson_days` | array\|null | — | 曜日配列（schedulesがない場合に使用） |
| `lesson_times` | array\|null | — | 時間帯配列（schedulesがない場合に使用） |
| `price` | string\|null | — | 月謝・料金（テキスト形式） |
| `monthly_fee` | number\|null | — | 月謝（円・数値） |
| `data_quality` | string\|null | — | `high` / `medium` / `low` |
| `data_sources` | array | — | 情報ソース |
| `last_verified_at` | string\|null | — | 最終確認日（ISO 8601: `2026-06-02`） |

### カテゴリ一覧

`サッカー` / `スイミング` / `ピアノ` / `英会話` / `ダンス` / `バレエ` / `体操` / `新体操` /
`チアダンス` / `武道` / `テニス` / `バスケットボール` / `野球` / `習字` / `そろばん` /
`学習塾` / `プログラミング` / `幼児教室`

## 重複チェックルール

新規データを追加する前に、以下の条件で既存データと照合する。

1. **教室名の完全一致**: 同名の教室は追加しない
2. **同一チェーンの同一拠点**: チェーン名＋地名の組み合わせが重複していないか確認
3. **住所の近接チェック**: 座標が100m以内で同カテゴリの場合は同一教室の可能性を要確認

---

## 収集禁止事項

- 利用規約でスクレイピングを禁止しているサイトからの自動収集（コドモブースター・スクルー等）
- SNS（Instagram・X・Facebook）からの自動収集（Meta/X APIの利用規約違反）
- 個人情報（講師の自宅住所・個人の電話番号など）の収集
