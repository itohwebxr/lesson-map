# 大手チェーン教室 ブランド分析（フェーズB）

## サマリー

調査した12ブランド全てに公式の教室一覧・検索ページが存在し、教室名・住所は概ね取得可能だが、月謝・曜日・緯度経度の公開度はブランドによって大きく異なる。スクレイピング難易度はほとんどが medium（JS レンダリングや検索フォーム依存）で、静的 HTML で網羅的な URL リストが取得できるブランドはヒューマンアカデミー（サイトマップあり）とペッピーキッズクラブが有望。大津市での教室数はコナミスポーツ（2拠点）・ヤマハ音楽（2拠点）・ペッピーキッズ（3教室）が確認でき、これらが最優先候補となる。

## 英会話系

### ECC 外語学院

- **一覧ページ**: https://www.ecc.jp/school/
- **詳細 URL 構造**: `/school/search.php?pn=滋賀県`（クエリパラメータ形式）
- **取得可能項目**:
  - 教室名 ✓ / 住所 ✓ / 緯度経度 ✗
  - 曜日・時間 △（コース別記載、教室別は要確認）
  - 対象年齢 △ / 月謝 △（コース別料金ページあり）
- **スクレイピング難易度**: medium（PHP+クエリパラメータ形式、403 応答でbot対策あり）
- **Extractor 価値**: medium（滋賀県内3校程度、大人向け英会話メイン）
- **備考**: 子ども向けは **ECC ジュニア**（eccjr.co.jp）が別ブランド。子ども向けデータ収集はそちらを優先すること

## 音楽系

### ヤマハ音楽教室

- **一覧ページ**: https://school.jp.yamaha.com/music/venues/
- **詳細 URL 構造**: `/music/venue/detail/?id=[数字ID]`（例: ?id=294180742）
  - 大津市内は JEUGIA ブランドが運営（大津テラス・大津京）
- **取得可能項目**:
  - 教室名 ✓ / 住所 ✓ / 緯度経度 ✗（地図・アクセス情報あり）
  - 曜日・時間 ✓（受付時間・レッスン曜日記載あり）
  - 対象年齢 ✓（幼児〜大人、コース別）
  - 月謝 ✓（ピアノ月2回 6,600円〜 等の料金表記あり）

- **Extractor 価値**: **high**（大津市内2拠点確認済み。全国約2,300教室。月謝情報も取得可能）
- **備考**: 大津市では JEUGIA ブランドが運営。本体 URL と異なるドメインに飛ぶ場合あり

## 優先実装ブランド

### 優先度: high

1. **ペッピーキッズクラブ** — 大津市内3教室確認済み。URL パターン明確。子ども専門英会話で LessonMap のコアターゲット
2. **コナミスポーツクラブ** — 大津市内2施設確認済み（本堅田・打出浜）。施設コードが体系的で月謝情報も掲載あり
3. **ヤマハ音楽教室** — 大津市内2拠点確認済み（JEUGIA 大津テラス・大津京）。月謝情報あり。全国2,300教室の規模

### 優先度: medium

4. **ヒューマンアカデミージュニア** — サイトマップ（/sitemap/school_list/）に静的都道府県別一覧あり。月謝情報あり。実装コストが最低クラス
5. **セイハ英語学院** — URL パターン明確（/classroom/[ID]/）。全国1,000教室超。大津市内の教室数を別途確認すべき
6. **HALLO** — URL パターン明確（/classrooms/detail/[ID]/）。FC 加盟塾で実施のため大津市内は要確認

### 優先度: low

7. **ECC 外語学院** — 大人向け英会話メイン（子ども向けは ECC ジュニアが別ブランド）
8. **Kids Duo** — 英語学童保育特化。全国210校と少なく大津市内の存在は不明
9. **セントラルスポーツ** — 大津市内拠点未確認。都市部中心展開
10. **ルネサンス** — 2025年4月の旧スポーツオアシス統合後のサイト構造が不安定
11. **リベルタ** — URL 構造が日本語スクール名エンコードで収集困難
12. **カワイ音楽教室** — 教室検索が SPA / ASP.NET 依存の可能性が高く実装コスト最大

**補足: robots.txt / 利用規約について**

全ブランドの robots.txt は WebFetch の403により直接確認不可。ヤマハ音楽教室の利用規約ページ（yamaha-ongaku.com/music-school/rules.html）、カワイはピアノ教室ネット向け規約（onken.kawai.jp/terms_piano.html）が存在。各ブランドともデータ収集前に利用規約の確認を強く推奨する。
