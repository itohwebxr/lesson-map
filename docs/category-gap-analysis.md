## 収録困難な教室の特徴

1. **個人ピアノ教室**: 大津市内に50〜80件存在するが、公式サイトを持たない・SEO弱い教室が多く、自動収集困難
2. **地域スポーツ少年団（スポ少）**: 大津市体育協会傘下に約38チーム。公式サイト未整備が多い
3. **ECCジュニア系**: 大津市内に推定30+教室あるが、個別フランチャイズ教室の情報は分散
4. **書道・習字個人教室**: 公開情報が極めて少なく、地域掲示板・地域情報誌への掲載が主
