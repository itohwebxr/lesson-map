# データソース分析レポート（フェーズA）

## サマリー

Google Places API（New）は営業時間・口コミ・概要テキストを構造化データで取得でき、LessonMapにとって最も即効性が高いが、Enterprise SKU で月1,000件の無料枠を超えると $17〜$20/1,000件のコストがかかる。習い事ポータル（スクルー・コドモブースター・スクスク）は曜日・月謝・対象年齢を最も詳しく掲載しているが、利用規約でのスクレイピング禁止が原則であり、正式な連携交渉が現実的。SNS（特にInstagram・X）は公式APIでの第三者データ収集が2025年以降ほぼ不可能になっており、実用性は低い。

## Tier2: Google Maps

### 取得可能フィールド

Places API（New）で取得できる主なフィールド（field mask で指定）：

| フィールド | 内容 | SKU ティア |
|---|---|---|
| `regularOpeningHours` | 通常営業時間（曜日・開閉時刻） | Enterprise |
| `currentOpeningHours` | 今後7日間の営業時間（特別日対応） | Enterprise |
| `editorialSummary` | 場所の説明テキスト（AI 生成または編集） | Enterprise + Atmosphere |
| `reviews` | 口コミ最大5件（テキスト・評価・著者） | Enterprise + Atmosphere |
| `types` / `googleMapsTypeLabel` | カテゴリ（「音楽教室」等180種類以上） | Basic |
| `priceLevel` | 価格帯（1〜4段階） | Enterprise |
| `displayName` / `formattedAddress` / `phoneNumber` | 基本情報 | Basic / Pro |

### 習い事情報の実用性

- **営業時間（曜日・時間）**: 教室が Google ビジネスプロフィールに正確に登録していれば高精度で取得可能。教室側が入力していない・誤っているケースも多い
- **対象年齢**: 専用フィールドなし。`editorialSummary` や `reviews` のテキストに含まれることがあるが構造化データとしては取得不可
- **月謝**: 専用フィールドなし。`priceLevel` は4段階の大まかな価格帯のみ。口コミに記載があることはあるが信頼性・網羅性は低い
- **カテゴリ**: 「音楽教室」「スポーツスクール」「学習塾」等のタイプラベルは取得可能。習い事の細分類には限界あり

### コスト・制限（2025年3月改定後）

| SKU | 無料枠（月） | 超過後の料金 |
|---|---|---|
| Basic（displayName 等） | 10,000件 | $5/1,000件 |
| Pro（phoneNumber 等） | 5,000件 | $17/1,000件 |
| Enterprise（openingHours, priceLevel） | 1,000件 | $20/1,000件 |
| Enterprise + Atmosphere（reviews, editorialSummary） | 1,000件 | $20+α/1,000件 |

大津市の習い事教室数を数百〜1,000件規模と想定すると、初期の一括取得は無料枠内に収まる可能性があるが、定期更新を行うとすぐに課金対象になる。

### LessonMapへの推奨度: **medium**

営業時間の補完には有効。月謝・対象年齢は補完できない。コストは小規模なら許容範囲。教室側の情報入力精度に依存する点がリスク。

## Tier3: ポータルサイト

### スクルー（skuroo.net）

**取得可能項目**:
- 曜日・受講時間: 掲載あり（教室側が入力）
- 月謝・費用: 掲載あり
- 対象年齢: 掲載あり
- 教室の特徴・説明テキスト: あり

子ども向け国内最大手の一つ（月間30万人保護者・約2万教室登録）。

**利用規約上の注意**:
「弊社システムを経由しない行為の禁止」規定が存在。スクレイピングの明示条項は未確認だが、無断転載・自動アクセスはグレーゾーン。

**推奨度**: スクレイピングは規約リスクあり。**API や公式連携交渉が現実的。medium（連携前提）**

---

### コドモブースター（kodomo-booster.com）

**取得可能項目**:
- 月謝: 掲載あり（教室ページに記載）
- 対象年齢: 検索フィルター機能あり・ページに記載
- 曜日・時間: 検索フィルターあり
- 口コミ: 体験者の口コミあり

国内利用者数 No.1（株式会社イトクロ運営）。全国10,000教室以上が体験申込対応。

**利用規約上の注意**:
利用規約ページは存在確認できたが直接フェッチは403でブロック。商業ポータルとしてデータの無断収集は禁止と想定。

**推奨度**: 月謝・対象年齢・曜日が三拍子揃う最有力サイト。**連携交渉優先度高。high（連携前提）**

---

### ジモティー（jmty.jp）

**取得可能項目**:
- 習い事・教室・スクールカテゴリあり
- 投稿者が自由記述するため、月謝・曜日・対象年齢が記載されているものもあるが**構造化されていない**
- 掲示板形式のため情報の鮮度・正確性が低い

**推奨度**: **low**。情報が非構造化・散発的で習い事教室の網羅的データ収集には不向き。

---

### エキテン（ekiten.jp by GMO）

**取得可能項目**:
- 習い事・スクールカテゴリあり（大津市の英会話教室 46件を掲載）
- 基本情報・2,000字の紹介文・写真・メニュー・クーポン
- 月謝情報: 「メニュー」欄に掲載可能
- 曜日・対象年齢: 自由記述テキスト内に含まれることがあるが専用フィールドなし

**推奨度**: **low〜medium**。習い事特化ではないため構造化データに限界。口コミ・基本情報の補完には使えるが専門ポータルに劣る。

---

### その他（追加発見サイト）

| サイト名 | 特記事項 | 推奨度 |
|---|---|---|
| **習い事スクスク**（sp-sukusuku.jp） | 国内最大級（121,373件）。月謝・コース・年齢を掲載。株式会社 Fanss 運営 | medium |
| **LessonPark**（lessonpark.jp） | 55万件超。Web 上の教室情報を**独自システムで自動収集**して構築。大津市エリアの網羅性が高い可能性 | high（連携交渉先として有望） |

**注目**: LessonPark は Web から自動収集して55万件を構築しているサービス。連携先候補として有力。

## Tier4: SNS

### Instagram

**取得可能性**:
2024年12月4日の Basic Display API 廃止以降、第三者データ収集は実質不可能：
- Graph API は自社アカウント（Business/Creator）の管理専用
- 他者の公開投稿を任意に検索・取得するエンドポイントは存在しない
- ハッシュタグ検索 API も2024年以降廃止済み

**推奨度**: **low**。公式 API での第三者教室情報収集は不可。スクレイピングは Meta 利用規約で明示禁止。

---

### Facebook

**取得可能性**:
- Pages の「営業時間」「住所」は Graph API で取得可能だが **Page Access Token（ページ管理者の OAuth 認証）が必要**
- 任意の公開 Page の情報を認証なしで一括取得することは API では不可
- 第三者 Page 情報を収集するには Meta App Review が必要で障壁が高い

**推奨度**: **low**。教室側が Facebook ページを正確に管理している割合も低下傾向。

---

### X（Twitter）

**取得可能性**:
- 2026年2月に全面 Pay-per-use 課金モデルへ移行（無料ティア廃止）
- 検索機能は Essential プラン以上（$100/月〜）が必要
- 習い事教室がスケジュールを X に投稿するケースは減少傾向

**推奨度**: **low**。コスト増・アクセス制限強化・教室の利用率低下の三重苦。実用性なし。

---

## LessonMapへのインパクト

| データ項目 | 最有力補完ソース | 難易度 |
|---|---|---|
| **曜日・時間** | Google Places API（営業時間）+ コドモブースター / スクルー | 中（API 課金 or 連携交渉） |
| **対象年齢** | コドモブースター / スクスク | 中（連携交渉必須） |
| **月謝** | コドモブースター / スクスク / スクルー | 中（連携交渉必須） |
| **カテゴリ** | Google Places API（types / typeLabel） | 低（API で取得容易） |
| **基本情報（住所・電話）** | Google Places API（Basic SKU・無料枠大） | 低 |

## 優先順位まとめ

### フェーズ1（今すぐ実施可能）

1. **Google Places API（New）** — 営業時間・カテゴリ・基本情報を構造化取得。field mask で Enterprise SKU を最小限に抑える設計が重要

### フェーズ2（交渉・連携）

2. **コドモブースター** — 月謝・対象年齢・曜日が三拍子揃う。株式会社イトクロへの API 提供交渉を推奨
3. **スクルー / 習い事スクスク** — 子ども向け特化の構造化データ。同様に公式連携を打診
4. **LessonPark** — 独自収集の55万件データベース。大津市データの提供交渉の価値あり

### フェーズ3（見送り推奨）

5. ジモティー — 非構造化・散発的情報
6. エキテン — 習い事専用ではなく構造化データ不足
7. Instagram / Facebook / X — 公式 API での第三者収集は2025年以降実質不可能
